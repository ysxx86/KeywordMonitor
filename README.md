## 使用方法

### 基本命令

- `/keyword` 或 `/关键词` - 打开配置界面
- `/keyword on` - 开启监控
- `/keyword off` - 关闭监控
- `/keyword set 关键词1,关键词2` - 设置关键词
- `/keyword debug` - 显示当前关键词解析结果

### 关键词规则

1. **单个关键词**：`MC` → 匹配包含 MC 的消息
2. **同时包含（AND）**：`MC+FS` 或 `MC#FS` → 必须同时包含 MC 和 FS
3. **排除关键词**：`MC&ZS` → 包含 MC 但不包含 ZS

示例：`MC+FS` 可匹配 "MC 24=1FS" 但不匹配 "MC 25=1"

### 关键词分组

点击配置界面中的"关键词分组"按钮：

1. **启用分组模式**：勾选后使用分组管理关键词，取消则使用传统单一关键词模式
2. **添加分组**：点击"添加分组"创建新的关键词组
3. **管理分组**：
   - 勾选复选框启用/禁用该组
   - 输入分组名称（如：组队、交易、招募）
   - 输入该组的关键词（规则同上）
   - 点击"删除"移除该组

**使用场景**：
- 组队组：MC,ZUG,TAQ,NAXX
- 交易组：WTS,WTB,收购,出售
- 招募组：招人,缺,来

每个组可以独立启用/禁用，非常灵活！

### 历史记录

点击配置界面中的"历史记录"按钮：

1. **查看历史**：显示最近100条匹配的消息
2. **搜索功能**：在搜索框输入关键词，点击"搜索"按钮过滤历史记录
3. **快速回复**：点击任意历史记录，弹出快速回复菜单
4. **清空历史**：点击"清空历史"按钮清除所有历史记录

历史记录包含：时间、频道、玩家名、消息内容

### 快速回复

点击配置界面中的"快速回复"按钮：

1. **添加模板**：在输入框输入常用回复，点击"添加"
2. **删除模板**：点击模板右侧的"删除"按钮
3. **使用模板**：
   - 在历史记录中点击任意消息
   - 选择一个回复模板
   - 自动向该玩家发送密语

**预设模板**：
- 有兴趣，密我
- 什么价格？
- 还在吗？

你可以根据需要添加更多模板！

### 统计数据

点击配置界面中的"统计数据"按钮：

1. **今日匹配次数**：显示今天匹配到的消息数量，每天0点自动重置
2. **总匹配次数**：显示累计匹配的所有消息数量
3. **最常匹配的关键词（Top 10）**：
   - 显示匹配次数最多的10个关键词
   - 了解哪些关键词最热门
   - 帮助优化关键词设置
4. **最活跃的时间段（Top 10）**：
   - 显示消息最多的10个小时段
   - 了解什么时候最适合组队/交易
   - 合理安排游戏时间
5. **24小时分布图**：
   - 可视化展示全天24小时的消息分布
   - 绿色：消息较少
   - 黄色：消息中等
   - 红色：消息最多
   - 灰色：无消息
6. **重置统计**：点击"重置统计"按钮清空所有统计数据

**统计数据用途**：
- 了解服务器活跃时间
- 优化关键词设置
- 分析副本组队规律
- 找出最佳交易时间

### 智能建议

点击配置界面中的"智能建议"按钮：

**工作原理**：
- 插件会自动分析每条匹配的消息
- 提取消息中的2-4字词汇
- 统计每个词汇出现的频率
- 当某个词汇出现次数达到阈值（默认5次）时，会建议添加为关键词

**功能特性**：
1. **自动学习**：无需手动操作，插件自动分析消息
2. **智能过滤**：
   - 自动排除已存在的关键词
   - 自动排除已忽略的建议词
   - 只显示真正有价值的建议
3. **定时提醒**：每小时检查一次，有新建议时自动提示
4. **可视化管理**：
   - 显示词汇和出现次数
   - 一键添加为关键词
   - 一键忽略不需要的词
   - 批量添加所有建议
   - 清空学习数据

**使用场景**：

**场景1：发现新的热门副本**
- 插件学习到"ICC"出现20次
- 提示："您近期频繁关注 ICC，是否将其设为关键词？"
- 点击"添加"，自动添加到关键词列表

**场景2：发现新的交易词汇**
- 插件学习到"金币"、"代练"等词汇
- 在智能建议界面查看所有高频词
- 选择需要的词汇添加

**场景3：优化关键词**
- 定期查看智能建议
- 发现一些无用的高频词
- 点击"忽略"，以后不再建议

**配置选项**：
- **启用智能学习**：勾选后开启自动学习功能
- **最小出现次数**：词汇至少出现多少次才建议（默认5次）
- **提醒间隔**：多久提醒一次（默认1小时）

**注意事项**：
- 智能学习会占用少量内存（约50KB）
- 可以随时清空学习数据
- 建议定期查看智能建议，及时添加有用的关键词

## 性能优化

插件采用了多项性能优化措施，确保低资源占用：

1. **哈希表缓存**：重复消息检测使用哈希表而非数组遍历，时间复杂度从 O(n) 降至 O(1)
2. **自动清理**：缓存数据超过 60 秒自动清理，避免内存泄漏
3. **按需加载**：独立窗口仅在启用时创建，减少初始化开销
4. **事件过滤**：仅注册已启用的频道事件，避免不必要的处理
5. **局部变量**：频繁调用的 API 函数缓存为局部变量，提升访问速度

这些优化使得插件即使在高频聊天环境下也能保持流畅运行。

## 常见问题

**Q：分组模式和传统模式有什么区别？**

A：
- 传统模式：所有关键词在一个输入框中，用逗号分隔
- 分组模式：关键词分成多个组，每组独立管理和启用

**Q：历史记录会占用很多内存吗？**

A：不会。历史记录最多保存100条，每条记录约1KB，总共约100KB，可以忽略不计。

**Q：快速回复会自动发送吗？**

A：是的。选择模板后会自动向该玩家发送密语，无需手动确认。

**Q：可以导出/导入配置吗？**

A：暂不支持，计划在v1.3.0版本中添加。

**Q：可以自定义历史记录数量吗？**

A：可以。在SavedVariables配置文件中修改`HistoryMaxCount`的值（默认100）。

**Q：统计数据会占用很多空间吗？**

A：不会。统计数据只记录数字，占用空间很小（约10KB）。

**Q：统计数据会自动重置吗？**

A：今日匹配次数每天0点自动重置，其他数据（总匹配次数、关键词统计、时间段统计）会一直累积，除非手动重置。

**Q：智能学习会影响性能吗？**

A：不会。智能学习只在匹配到消息时才工作，占用资源极少。学习数据约50KB，可以忽略不计。

**Q：智能建议的词汇准确吗？**

A：智能建议基于词频统计，会提取消息中的高频词汇。但不是所有高频词都有用，需要用户自己判断是否添加。

**Q：如何关闭智能学习？**

A：打开"智能建议"界面，取消勾选"启用智能学习"即可。

**Q：如何重置所有配置？**

A：删除 `WTF\Account\你的账号\SavedVariables\KeywordMonitorDB.lua` 文件，然后 `/reload` 重载界面。

## 故障排除

### 问题1：插件无法加载

**解决方案**：
1. 检查文件夹名称是否为 `KeywordMonitor`
2. 确认 `.toc` 文件存在
3. 尝试 `/reload` 重载界面

### 问题2：关键词不匹配

**检查清单**：
1. 确认已启用监控（`/keyword on`）
2. 确认关键词格式正确（用逗号分隔）
3. 确认选择了正确的频道
4. 使用 `/keyword debug` 查看关键词解析结果
5. 检查是否在黑名单中

### 问题3：历史记录不显示

**解决方案**：
1. 确认已有匹配的消息
2. 尝试关闭并重新打开历史记录界面
3. 检查是否被过滤（好友、自己、黑名单）

### 问题4：快速回复无法发送

**解决方案**：
1. 确认玩家名称正确
2. 确认玩家在线
3. 检查是否被对方屏蔽

### 问题5：统计数据不准确

**解决方案**：
1. 确认插件已启用监控
2. 检查是否有消息被过滤（好友、黑名单）
3. 尝试重置统计数据重新开始

### 问题6：智能建议没有数据

**解决方案**：
1. 确认已启用智能学习
2. 继续使用插件，积累足够的数据
3. 检查最小出现次数设置（默认5次）

### 问题7：智能建议的词汇不准确

**解决方案**：
1. 这是正常现象，智能学习基于词频统计
2. 点击"忽略"按钮排除无用的词
3. 只添加真正有用的建议词

- 每天查看智能建议

- 结合统计数据优化设置

- 关键词不要设置过多（建议每组不超过20个）
- 定期清理历史记录
- 不需要的分组及时禁用
- 避免过于宽泛的关键词（如"的"、"了"等）

- 不要将密码等敏感信息设为快速回复
- 谨慎使用快速回复，避免误发
- 定期检查黑名单，避免误加好友
