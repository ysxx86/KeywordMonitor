## 使用方法

### 基本命令

- `/keyword` 或 `/关键词` - 打开配置界面
- `/keyword on` - 开启监控
- `/keyword off` - 关闭监控
- `/keyword set 关键词1,关键词2` - 设置关键词
- `/keyword debug` - 显示当前关键词解析结果
- `/keyword memory` - 内存诊断
- `/keyword optimize` - 优化内存

### 关键词规则

1. **单个关键词**：`MC` → 匹配包含 MC 的消息
2. **同时包含（AND）**：`MC+FS` 或 `MC#FS` → 必须同时包含 MC 和 FS
3. **排除关键词**：`MC&ZS` → 包含 MC 但不包含 ZS

示例：`MC+FS` 可匹配 "MC 24=1FS" 但不匹配 "MC 25=1"

### 关键词分组

点击配置界面中的"关键词分组"按钮：

1. **启用分组模式**：勾选后使用分组管理关键词，取消则使用传统单一关键词模式
2. **添加分组**：点击"添加分组"创建新的关键词组
3. **管理分组**：
   - 勾选复选框启用/禁用该组
   - 输入分组名称（如：组队、交易、招募）
   - 输入该组的关键词（规则同上）
   - 点击"删除"移除该组

**使用场景**：
- 组队组：MC,ZUG,TAQ,NAXX
- 交易组：WTS,WTB,收购,出售
- 招募组：招人,缺,来

每个组可以独立启用/禁用，非常灵活！

### 历史记录

点击配置界面中的"历史记录"按钮：

1. **查看历史**：显示最近100条匹配的消息
2. **搜索功能**：在搜索框输入关键词，点击"搜索"按钮过滤历史记录
3. **快速回复**：点击任意历史记录，弹出快速回复菜单
4. **清空历史**：点击"清空历史"按钮清除所有历史记录

历史记录包含：时间、频道、玩家名、消息内容

### 快速回复

点击配置界面中的"快速回复"按钮：

1. **添加模板**：在输入框输入常用回复，点击"添加"
2. **删除模板**：点击模板右侧的"删除"按钮
3. **使用模板**：
   - 在历史记录中点击任意消息
   - 选择一个回复模板
   - 自动向该玩家发送密语

**预设模板**：
- 有兴趣，密我
- 什么价格？
- 还在吗？

你可以根据需要添加更多模板！

### 预设方案

点击"关键词分组"界面中的"预设方案"按钮：

**内置预设方案**：
1. **经典副本组队**
   - 包含：MC、BWL、TAQ、NAXX等副本关键词
   - 适合：寻找副本组队的玩家
   - 快速回复：有位置吗？、什么职业？、还缺几个？

2. **G团猎人**
   - 包含：G团+LR、敏捷、命中等关键词
   - 适合：猎人职业参加G团
   - 快速回复：猎人来、装备怎么分？、多少金？

3. **材料商人**
   - 包含：收购、出售、常见材料等关键词
   - 适合：做材料买卖的商人
   - 快速回复：什么价格？、还有吗？、在哪交易？

4. **日常任务**
   - 包含：日常、任务、声望等关键词
   - 适合：做日常任务和刷声望的玩家
   - 快速回复：一起做吗？、在哪？、组我

5. **PVP战场**
   - 包含：战场、竞技场等关键词
   - 适合：喜欢PVP的玩家
   - 快速回复：组我、什么段位？、来

**使用方法**：
1. 点击"预设方案"按钮
2. 浏览内置预设和自定义预设
3. 点击"应用"按钮一键加载预设
4. 预设会自动配置关键词分组和快速回复

**保存自定义预设**：
1. 配置好你的关键词分组和快速回复
2. 在预设方案界面底部输入预设名称
3. 点击"保存"按钮
4. 你的配置会保存为自定义预设，随时可以重新应用

2. 粘贴之前导出的配置文本
3. 点击"导入"按钮
4. 系统自动应用配置

**注意事项**：

为关键词组设置自动启用时间段：

**功能说明**：
- 为每个关键词组设置生效时间段
- 到达指定时间自动启用该组
- 超出时间范围自动禁用该组
- 支持跨天时间段（如22:00-2:00）

**使用场景**：
- 公会每天20:00-23:00打副本，自动启用副本组
- 服务器高峰期18:00-22:00交易活跃，自动启用交易组

- 每分钟检查一次时间触发条件
- 自动启用/禁用不会影响手动设置
- 时间触发数据保存在配置中，重启游戏不丢失

## 性能优化

插件采用了多项性能优化措施，确保低资源占用：

1. **哈希表缓存**：重复消息检测使用哈希表而非数组遍历，时间复杂度从 O(n) 降至 O(1)
2. **自动清理**：缓存数据超过 60 秒自动清理，避免内存泄漏
3. **按需加载**：独立窗口仅在启用时创建，减少初始化开销
4. **事件过滤**：仅注册已启用的频道事件，避免不必要的处理
5. **局部变量**：频繁调用的 API 函数缓存为局部变量，提升访问速度

这些优化使得插件即使在高频聊天环境下也能保持流畅运行。

## 常见问题

**Q：分组模式和传统模式有什么区别？**

A：
- 传统模式：所有关键词在一个输入框中，用逗号分隔
- 分组模式：关键词分成多个组，每组独立管理和启用

**Q：历史记录会占用很多内存吗？**

A：不会。历史记录最多保存100条，每条记录约1KB，总共约100KB，可以忽略不计。

**Q：快速回复会自动发送吗？**

A：是的。选择模板后会自动向该玩家发送密语，无需手动确认。

**Q：可以导出/导入配置吗？**

A：暂不支持，计划在v1.3.0版本中添加。

**Q：可以自定义历史记录数量吗？**

A：可以。在SavedVariables配置文件中修改`HistoryMaxCount`的值（默认100）。

**Q：统计数据会占用很多空间吗？**

A：不会。统计数据只记录数字，占用空间很小（约10KB）。

**Q：统计数据会自动重置吗？**

A：今日匹配次数每天0点自动重置，其他数据（总匹配次数、关键词统计、时间段统计）会一直累积，除非手动重置。

**Q：预设方案会覆盖我的配置吗？**

A：是的。应用预设方案会清空现有分组并加载预设配置。建议先导出备份当前配置。

**Q：可以修改内置预设吗？**

A：不能直接修改内置预设，但可以应用后修改，然后保存为自定义预设。

**Q：导出的配置文本很长，正常吗？**

A：正常。配置使用Base64编码，会比较长。请完整复制，不要遗漏。

**Q：导入配置失败怎么办？**

A：检查以下几点：
1. 配置文本是否完整复制
2. 是否有多余的空格或换行
3. 配置文本是否被修改过

**Q：时间触发不生效？**

A：检查以下几点：
1. 确认已为关键词组设置时间触发
2. 确认当前时间在设置的时间段内
3. 等待1分钟，系统每分钟检查一次

**Q：时间触发会影响手动启用吗？**

A：时间触发会自动修改关键词组的启用状态。如果你手动修改，下次检查时会被时间触发覆盖。

**Q：趋势数据会占用很多空间吗？**

A：不会。每日数据只记录数字，每小时数据自动清理（保留48小时），总占用约20KB。

**Q：趋势分析显示的数据不准确？**

A：检查以下几点：
1. 确认插件已启用监控
2. 确认有足够的历史数据（至少使用几天）
3. 检查是否有消息被过滤（好友、黑名单）

**Q：关联分析没有数据？**

A：关联分析需要消息中匹配多个关键词才会记录。如果你的关键词都是单独出现，不会有关联数据。建议使用更宽泛的关键词。

**Q：如何清空趋势和关联数据？**

A：目前没有单独清空按钮，可以通过"重置统计"清空所有统计数据（包括趋势和关联）。

**Q：添加组合关键词后不生效？**

A：添加组合关键词后会立即生效。如果不生效，检查：
1. 确认插件已启用
2. 确认关键词格式正确（用+连接）
3. 使用 /keyword debug 查看关键词解析结果

**Q：快速回复为什么要二次确认？**

A：为了防止误操作。确认对话框会显示目标玩家和回复内容，避免发错消息。

**Q：内存占用过高怎么办？**

A：
1. 打开性能监控界面
2. 点击"立即清理旧数据"
3. 减少数据保留天数（如改为3天）
4. 减少不必要的关键词

**Q：如何关闭自动清理？**

A：打开性能监控界面，取消勾选"自动清理旧数据"。但不建议关闭，会导致数据越来越多。

**Q：清理旧数据会影响什么？**

A：只会清理超过保留天数的每日趋势数据，不会影响：
- 统计数据（今日匹配、总匹配等）
- 关键词设置
- 历史记录
- 快速回复
- 其他配置

**Q：首次安装为什么显示欢迎信息？**

A：这是正常的。首次安装会显示欢迎信息和使用说明，帮助新用户快速上手。

**Q：更新后为什么显示更新日志？**

A：让用户了解新版本的功能和改进。只在版本更新时显示一次。

**Q：如何重置所有配置？**

A：删除 `WTF\Account\你的账号\SavedVariables\KeywordMonitorDB.lua` 文件，然后 `/reload` 重载界面。

### 问题1：插件无法加载

**解决方案**：
1. 检查文件夹名称是否为 `KeywordMonitor`
2. 确认 `.toc` 文件存在
3. 尝试 `/reload` 重载界面

### 问题2：关键词不匹配

**检查清单**：
1. 确认已启用监控（`/keyword on`）
2. 确认关键词格式正确（用逗号分隔）
3. 确认选择了正确的频道
4. 使用 `/keyword debug` 查看关键词解析结果
5. 检查是否在黑名单中

### 问题3：历史记录不显示

**解决方案**：
1. 确认已有匹配的消息
2. 尝试关闭并重新打开历史记录界面
3. 检查是否被过滤（好友、自己、黑名单）

### 问题4：快速回复无法发送

**解决方案**：
1. 确认玩家名称正确
2. 确认玩家在线
3. 检查是否被对方屏蔽

### 问题5：统计数据不准确

### 推荐配置 - 休闲玩家
- 启用分组模式
- 创建"组队组"和"交易组"
- 根据需要切换启用
- 添加3-5个常用快速回复

### 推荐配置 - 硬核玩家
- 启用分组模式
- 为每个副本创建专用分组
- 添加10+个快速回复模板
- 定期查看历史记录
- 每周查看统计数据优化关键词

### 推荐配置 - 商人玩家
- 启用分组模式
- 创建"收购组"和"出售组"
- 添加价格询问相关的快速回复
- 利用历史记录追踪交易信息
- 查看统计数据找出最佳交易时间

### 推荐配置 - 数据分析玩家
- 启用所有频道监控
- 设置宽泛的关键词
- 定期查看统计数据
- 分析服务器活跃规律
- 根据数据调整游戏策略
- 每周查看趋势分析
- 每周查看关联分析
- 根据分析结果优化关键词

### 性能建议
- 关键词不要设置过多（建议每组不超过20个）
- 定期清理历史记录
- 不需要的分组及时禁用
- 避免过于宽泛的关键词（如"的"、"了"等）

### 安全建议
- 不要将密码等敏感信息设为快速回复
- 谨慎使用快速回复，避免误发
- 定期检查黑名单，避免误加好友
