## 功能特性

- 监控多个聊天频道（频道、说、大喊、密语、公会、队伍、团队）
- 支持单个关键词、组合关键词（AND）、排除关键词
- 可输出到系统聊天窗口或独立窗口
- 自动过滤好友和自己的消息
- 自动过滤重复消息
- 玩家黑名单（屏蔽特定玩家）
- 关键词黑名单（屏蔽包含特定词的消息）
- 提示音提醒
- 战斗中自动隐藏（可选）

## 使用方法

### 基本命令

- `/keyword` 或 `/关键词` - 打开配置界面
- `/keyword on` - 开启监控
- `/keyword off` - 关闭监控
- `/keyword set 关键词1,关键词2` - 设置关键词
- `/keyword debug` - 显示当前关键词解析结果

### 关键词规则

1. **单个关键词**：`MC` → 匹配包含 MC 的消息
2. **同时包含（AND）**：`MC+FS` 或 `MC#FS` → 必须同时包含 MC 和 FS
3. **排除关键词**：`MC&ZS` → 包含 MC 但不包含 ZS

示例：`MC+FS` 可匹配 "MC 24=1FS" 但不匹配 "MC 25=1"

### 按钮操作（如果有 NDui）

- 左键 - 打开配置界面
- 右键 - 启用/关闭监控

### 按钮操作（原生 UI）

- 左键 - 打开配置界面
- 右键 - 启用/关闭监控
- Shift+拖拽 - 移动按钮位置（位置会自动保存）

## 兼容性

- 支持 WoW 3.4.3（巫妖王之怒）
- 内置两种界面风格：暴雪原生 UI 和 NDui 简洁风格

## 配置说明

所有配置保存在 `KeywordMonitorDB` 变量中，包括：

- 启用状态
- 关键词列表
- 监控频道选择
- 输出模式（系统窗口/独立窗口）
- 提示音开关
- 窗口闪动开关
- 战斗隐藏开关
- NDui 美化开关
- 玩家黑名单
- 关键词黑名单

### 频道选择

点击配置界面中的"频道选择"按钮，可以选择要监控的频道：

- 频道聊天（默认开启）
- 说
- 大喊
- 密语
- 公会
- 队伍
- 团队

可以同时监控多个频道。

### 黑名单管理

点击配置界面中的"黑名单管理"按钮，可以管理黑名单：

**玩家黑名单**：
- 输入玩家名称，点击"添加"即可屏蔽该玩家的所有消息
- 点击"清空玩家黑名单"可以清空所有玩家黑名单

**关键词黑名单**：
- 输入关键词，点击"添加"即可屏蔽包含该关键词的所有消息
- 点击"清空关键词黑名单"可以清空所有关键词黑名单

黑名单优先级高于关键词匹配，即使消息匹配了关键词，如果在黑名单中也会被过滤。

### NDui 美化

插件内置了两种界面风格，可以在配置界面中自由切换：

- **暴雪原生风格**（默认）：使用魔兽世界原生的对话框背景和边框，经典传统
- **NDui 简洁风格**：使用简洁的黑色细边框，现代简约

勾选"使用 NDui 美化风格"即可切换，更改后需要 `/reload` 重载界面生效。

注意：这个美化风格是插件内置的，不需要安装 NDui 插件也可以使用。

## 注意事项

- 关键词不区分大小写
- 自动过滤标点符号和空格
- 60秒内的重复消息会被过滤
- 好友消息不会被监控
